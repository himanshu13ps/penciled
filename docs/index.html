Architecture diagrams, sketched in pencil.

penciled turns a few lines of JSON into a diagram that looks drawn by hand: graphite grain, hatched shading, corners that overshoot. It lays itself out, checks itself, and runs anywhere Node does.

$npx skills add himanshu13ps/penciled

How it works

Describe it, check it, draw it

Your agent does all three when you ask for a sketch. You can also run them yourself.

Describe

Nodes, the groups around them, and arrows between them. Shapes carry meaning: cylinders for data, clouds for things you don't run.

{
  "nodes": [
    { "id": "api", "label": "API",
      "shape": "rounded" },
    { "id": "db", "label": "Orders",
      "shape": "database" }
  ],
  "edges": [
    { "from": "api", "to": "db" }
  ]
}

Check

The validator lays the diagram out exactly as it will be drawn and says what to change. Agents fix their own input this way.

$ penciled validate shop.json
warning edges: 1 arrow crossing:
  orders → payments × catalog → db.
  Try the other direction, or move one
  end into the same group as the other
shop.json: 0 errors, 1 warning

Draw

An SVG for docs and slides, or the interactive viewer. The same seed always gives the same drawing.

$ penciled shop.json -o shop.svg
$ penciled shop.json -o shop.html
$ penciled shop.json -o v2.svg \
    --seed 42

Use it

Two ways in

Install it as a skill and ask for diagrams in plain words, or call the command line directly.

With your agent

Works with Claude Code, Cursor, Codex, OpenCode and other agents that read skills.

$npx skills add himanshu13ps/penciled

Then ask:

“sketch the architecture of this repo as a hand-drawn diagram”

From the command line

Clone the repo; there is nothing to install.

penciled d.json -o d.svgDraw an SVG
penciled d.json -o d.htmlThe interactive viewer
penciled validate d.jsonCheck without drawing
--seed 42A different take, reproducibly
--strictFail on warnings, for CI

Here penciled is node skills/penciled/src/cli.js. Full input reference in the schema docs.
