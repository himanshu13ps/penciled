Features

What you can describe

A diagram is nodes, the groups around them and the arrows between them. Shapes carry meaning, so readers know a database from a service at a glance. Open any card to see the JSON behind it.

Styles

Make it your own

Paper, ruling and pencil are one line each. A seed gives you a different hand-drawn take on the same diagram, and the same seed always draws it the same way.

Checks

It checks its own work

Before drawing, penciled validates the input and lays the diagram out exactly as it will be drawn. Errors mean it can't be drawn as written. Warnings mean it will draw, but probably not the way you want. Every message says what to change, which is how an agent fixes its own diagrams. The messages below are produced live.

Outputs

An SVG, a PNG, or a page people can play with

All come from the same input and seed, so they match, and the handwriting font is built in. For places that don't show SVG, like chat apps and email, write a PNG: -o diagram.png (it uses Chrome, Edge, Chromium or Brave if you have one installed).

SVG

For READMEs, docs sites, wikis and slides. Scales to any size and stays sharp.

  • One self-contained file, about 100 to 400 KB
  • Opens in any browser; edits in vector tools
  • penciled diagram.json -o diagram.svg

Get it

Three ways to use it

All free, all offline. The only requirement for the first two is Node.js 18 or later.

1Ask your agent

Install it as a skill. Your agent learns when to use it and how to write, check and draw the diagram.

$npx skills add himanshu13ps/penciled

Then ask in your own words:

“sketch the architecture of this repo as a hand-drawn diagram”

2Command line

Clone the repo; there is nothing else to install.

$ git clone \
    https://github.com/himanshu13ps/penciled
$ cd penciled
$ node skills/penciled/src/cli.js \
    examples/web-app.json -o web-app.svg

Use -o out.png for a PNG, -o out.html for the viewer, validate to check without drawing, --seed for another take.

3In your browser

Use the playground on this page. Write or paste the JSON, pick a paper and pencil, and download SVG, PNG or JPG. Nothing to install, nothing uploaded.

FAQ

Questions and limits

What is an agent skill?

A folder of instructions (and, here, code) that an AI coding agent such as Claude Code, Cursor or Codex can load when a task calls for it. penciled's skill tells the agent when a hand-drawn diagram fits, how to describe the system, how to read the validator's messages and how to render the result.

Do I need an AI agent to use it?

No. You can write the JSON yourself and run the command line, or use the playground on this page without installing anything.

What kinds of diagrams can it draw?

Architecture and system diagrams: services, databases, queues, people, external systems, documents, the groups around them and the arrows between them. It isn't for charts of numbers, UI mockups or precise engineering drawings.

A diagram can have up to 40 nodes, 12 groups and 80 arrows. Hand-drawn diagrams read best under about 15 nodes; bigger systems work better as an overview plus a few detail diagrams.

Is anything sent to a server?

No. penciled runs entirely on your machine, or in your browser on this page. It makes no network requests and collects nothing.

Can I place things exactly where I want?

Yes. Layout is automatic by default, but if every node has a position, penciled uses your positions as given. See the event pipeline in the gallery.

How do I get the same drawing every time?

Set paper.seed. The same input and seed always produce the same drawing, so you can edit a label and re-render without the whole sketch changing character. In the viewer, save the JSON to keep the seed you liked.

Can I get a PNG or JPG?

Yes, three ways. In the playground on this page, use the PNG or JPG buttons. In the interactive viewer, use its PNG or JPG button. From the command line, write to a .png file: penciled diagram.json -o diagram.png. That uses Chrome, Edge, Chromium or Brave if one is installed; without one, it tells you so and you can save a PNG from the viewer instead.

Images are twice the drawing's size by default, sharp enough for slides. PNGs keep every detail but run to several megabytes because of the paper grain; JPG is about a tenth of the size.

Can I edit the drawing afterwards?

Edit the JSON and render again; that's the intended way. The SVG is a normal vector file, so you can also open it in a vector editor, though it is made of many small pencil strokes.

How big are the files?

Usually 100 to 400 KB for an SVG and about 160 KB for the viewer. PNGs from the command line are twice the drawing's size by default; use --scale 1 for smaller files. The paper grain and the embedded font are most of it. PNGs are larger, often several megabytes, because the paper grain doesn't compress; JPG is about a tenth of the size and fine for sharing.

What does it cost, and what's the licence?

It's free and open source under the MIT licence. The handwriting font, Caveat, is under the SIL Open Font License.
